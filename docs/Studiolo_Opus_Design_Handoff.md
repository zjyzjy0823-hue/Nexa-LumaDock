# Studiolo 桌面与移动端设计交接

请为 Studiolo 重新设计 Android 手机端和 Windows／macOS 桌面端的完整产品体验。可以从首页、导航和页面组织重新构思，也可以重新定义视觉、组件和动效。两端属于同一个产品，各自按屏幕空间、输入方式和使用场景设计。

## Studiolo 的产品方向

Studiolo 是一个个人工作台。用户可以在里面记账、收藏网站、管理结构化记录与设备，也能跨设备共享内容、跟 Agent 聊天、查看和管理定时任务。在手机上，用户常常只想快速记一笔、找一条记录或看看任务跑完了没有。在电脑上，用户有更大的空间浏览、编辑和管理这些内容。

- **Local-first 与多端同步。** 已落地到设备的数据在断网时仍可使用，能离线编辑的内容先保存到本机，联网后同步。界面可以把「已在本机保存」「待同步」「需要处理冲突」表达清楚。
- **Shared Space。** 用于跨设备共享小型文件、文本、配置和 Key。每次读取内容都要重新输入密码，包括离线和 API 读取。原型可以演示锁定、输入密码、查看内容，以及再次打开时重新验证。密码恢复等细节仍待确认。
- **Agent Chat。** 优先支持 OpenClaw 和 Hermes。历史由对应 Agent 服务提供，Studiolo 不保留聊天正文或跨端聊天缓存。可以把重点放在切换 Agent、继续会话、流式回复和连接中断时的体验。聊天附件仍待确认。
- **任务与自动化。** 在同一处管理 Studiolo 原生任务和 Agent 原生 Cron。每个任务只有一个调度所有者，用户应能看出任务由谁运行，以及去哪里查看历史与结果。
- **主题。** Liquid Glass 是可选主题。可以自由探索常规主题的视觉方向、材质和密度，也可以用动效表达状态变化。在手机上，可以示意关闭模糊或减少动态效果后的体验。

## 手机端与桌面端

**手机端采用常见的底部标签导航。** 给最常用的一级入口稳定的位置，用图标和短标签表达当前选中项。底栏应容易触达，用户切换页面时能预期自己会去哪儿。具体放几个入口、叫什么、如何归类，以及快捷新增放在哪里，都由你根据设计判断。

**桌面端可以重构整个工作台。** 当前产品有首页、网站、设备、Agent、数据、账本、自动化、API 和设置，加上规划中的 Shared Space、Agent Chat 和统一任务管理。这些是需要在新体验里找到归属的能力。你可以重新组织导航、桌面布局、信息密度和操作入口，决定哪些功能适合并排查看、哪些适合单独进入。

## 希望看到的交付

用可直接打开的 HTML 展示手机和桌面两端的设计方向，配上有代表性的 CSS 样式和交互动效。可以做成单页切换，也可以分成两个 HTML。整体导航和页面归属能看懂即可，重点画面可以挑你认为最能说明方案的场景，用模拟数据演示。

你可以从首页、数据浏览、Shared Space、Agent Chat 或任务管理中挑几段代表性流程做细。选一套你最推荐的方向，简短说明手机底栏如何取舍，以及桌面如何利用额外空间。页面数量、品牌色、视觉风格、组件形态和具体动画由你决定。
