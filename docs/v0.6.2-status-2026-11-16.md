## 本轮交付（2026-11-15 → 11-16）

### 同步与恢复
- Sync Protocol v3 契约包与三语言校验器；`snapshot` / `resync` 完整恢复链路（用户选 C 方案）
- `rejected` 出口：列表 + dismiss + retry，设置页卡片，端到端实测（拒绝 → 重试 → Core 收到 → 归零）
- resync 以快照为权威，支持 Core 回滚；`sync_in_progress` 409 改为有上限等待

### 数据读取（本轮最后一块）
- `GET /data/collections?include_records=false&q=`：摘要 + SQL 聚合计数
- `GET /data/collections/{id}/records?page=true&limit=&cursor=&q=`：HMAC 签名游标分页
- `GET /data/overview`：总数 / 完成数 / 最近记录
- 实测：5 万条摘要 **238B / 174ms**、分页 **12KB / 324ms**、深页 338ms；旧接口对照 **166MB / 5.1s**
- 前端数据页全量切换：服务端搜索、加载更多、编辑前取详情；新增 17 条测试并接入 CI

### Codex 交叉审查修掉的真实缺陷
| 缺陷 | 后果 |
| --- | --- |
| `agent_completed` 对连接 Local 的智能体永不触发 | 自动化功能对插件用户等于不存在（已改为 Client 凭据上报 + Local 队列，迁移 0019） |
| `rowcount == 0` 判重（PG 恒返回 1） | PG 上重复事件会错报 `duplicated:false`（改用 `RETURNING`） |
| 适配器 claim 后心跳在 try 外 | 一次抖动就让任务永久 running、适配器退出（改为有界重试后释放） |
| `_apply_entity` 的 echo 语义作用于快照 | Core 回滚后本地旧数据永远盖不回来（仅在快照路径允许回退） |
| 前端发无偏移时间 | 跨时区错月（改为带偏移 ISO） |
| 已同步交易回传被删分类 id | 只改备注也 404（仅在分类真的变化时校验） |

### 防假承诺
