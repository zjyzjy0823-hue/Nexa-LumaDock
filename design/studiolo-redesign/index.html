核心体验约束与原型还原

完整覆盖交接文档中的 4 条关键产品规则

01 · Local-first

离线可写与状态递进

任意新建记账、收藏网站或解决冲突，都先落盘显示「已在本机保存」，随后推进为「待同步」并在联网后变为「已同步」。切换到离线模式可体验断网继续记录与联网自动补齐。

02 · Shared Space

每次读取都重新验密

锁定状态下不泄露任何对象文件名，仅显示数量与本机副本数；解锁目录输入一次密码，查看/复制/导出每个对象都须再验一次密码（演示密码 studiolo），切离或退后台立即抹除明文。

03 · Agent Chat

零正文持久化与断线恢复

支持 OpenClaw 与 Hermes 双 Agent 切换，明确提示对话历史由上游 Agent 实时提供、Studiolo 不做跨端缓存。支持在流式输出途中模拟断网，查看「中断」标记与重连同步体验。

04 · 统一任务

单所有者调度与能力边界

Studiolo 原生任务、OpenClaw Cron 与 Hermes Cron 在同一列表呈现，每行明确标出调度所有者及运行实例。对于无历史接口或离线不可达的外部任务，直接禁用操作并说明原因。

推荐验证场景（可直接在两端原型中操作）

场景 1 · 断网与冲突合并 离线记账 & 字段级合并

在顶部控制条切到「离线」记一笔账，观察本机保存态；再去数据页处理 Spotify 家庭的冲突，恢复联网后观察队列自动清空。

场景 2 · 按次验密门禁 Shared Space 解锁

打开共享空间输入演示密码 studiolo 进入目录，再点任一对象读取明文触发二次验密；切换页面或标签页返回后自动重新锁定。

场景 3 · 流式中断与重连 Agent Chat 断网

发送消息并在 AI 流式回复过程中切到顶部「离线」，回复会暂停并标为「中断」；切回「在线」后显示重连状态并从上游恢复。

场景 4 · 主题与性能降级 Liquid Glass 与无障碍

将顶部控制条切到「Liquid Glass」，再分别关闭「模糊」与开启「减少动效」，对比材质降级与视图过渡的克制表现。
